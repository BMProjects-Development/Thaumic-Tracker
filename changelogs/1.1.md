# Thaumic Tracker 1.1

## English

- Ported to Minecraft 1.21.1 and NeoForge with Thaumaturge 1.1.0.
- Restored the pin ribbon, including selecting research and retaining the selection after resizing the book.
- Switched aspect balance and discovery queries to Thaumaturge's public API.
- Tracks the updated research tree and new entries directly from the registry, including component-specific items such as vis crystals.
- Removed Better Advanced Tooltips from development and test dependencies; Thaumaturge no longer requires it.
- Updated the development NeoForge version and automated compatibility checks.
- Expanded integration tests for crystal aspects, alternative smithing templates, later theory notes, server costs, and client aspect synchronization.

This build targets Minecraft 1.21.1 and the Thaumaturge 1.1 series.
Existing saved selections and hotkeys are preserved. Install Tracker on the client; servers do not need it.

## Русский

- Добавлена поддержка Minecraft 1.21.1 на NeoForge с Thaumaturge 1.1.0.
- Восстановлена закладка отслеживания: выбор исследования сохраняется и после изменения размера книги.
- Проверки запаса очков и открытия аспектов переведены на публичный API Thaumaturge.
- Обновлённое дерево и новые исследования читаются из реестра, включая предметы с обязательными компонентами, например кристаллы vis.
- Better Advanced Tooltips удалён из зависимостей разработки и тестов: Thaumaturge больше его не требует.
- Обновлены версия NeoForge для разработки и автоматические проверки совместимости.
- Расширены интеграционные проверки аспектов кристаллов, альтернативных кузнечных шаблонов, записок поздних этапов, серверных затрат и синхронизации очков аспектов.

Сборка предназначена для Minecraft 1.21.1 и ветки Thaumaturge 1.1.
Сохранённый выбор и горячие клавиши остаются прежними. Tracker устанавливается на клиент; серверу он не нужен.
