# Thaumic Tracker 1.0.1

## Added

- A mod icon in the NeoForge mod list, with smoothing disabled to keep the
  pixel art sharp.
- Release history with separate notes for each version, also included in the ZIP.

## Improved

- A shorter README and clearer Russian and English guides focused on playing.
- Build and release instructions now live in `CONTRIBUTING.md`.
- Republishing the same version replaces its release files and updates its tag
  to the tested commit. New versions preserve earlier releases.
- GitHub release descriptions use the matching changelog. Missing notes fail
  validation, and outdated builds cannot replace a newer build.

Research tracking and controls are unchanged.
